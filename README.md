## Single Bible App

Setup steps:

1. Install dependencies
2. Setup android/ios emuluator (https://docs.expo.dev/workflow/android-studio-emulator/, https://docs.expo.dev/workflow/ios-simulator/)
3. Change the bible data in constants/index.js to the bible you want to use from Door43
4. Run `npm run build:android` to bundle the bible and install it on your android emulator
5. Run `npm start` to start the metro bundler
